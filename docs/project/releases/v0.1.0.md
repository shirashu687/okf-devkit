# v0.1.0 公開予定のリリースノート

**現在未公開。** これは初回の公開予定内容をレビューする文書であり、タグ・GitHub Release・配布URLの存在を示さない。予定はGitHub上の公開済みPreReleaseで、安定版やLatestとして扱わない。準備PRのレビューとmain統合、その最終SHAのCI成功後に、タグ用workflowとDraftの実物を検査する。タグ作成・公開は別の明示的な承認を受けた工程である。

## 利用できること

- PythonとNodeで、文書のindex生成、Git履歴のlog、lint、stale、affected、新規文書、backlog集計、HTML生成、syncを利用できる。目的別helpと[日常操作ガイド](/agents/operate-okf.md)から操作を選べる。
- 新規のコード由来文書には根拠パスを複数の`--code-globs`で指定する。4つの必須型では省略を拒否し、本文補完後のindex/lint確認へつなげる。
- HTMLには階層ナビゲーション、本文・ソースへのリンク、読み取り専用のbacklog状態一覧と件数がある。リスト/カンバン切替、検索、状態別の開閉を利用でき、表示操作でMarkdownを変更しない。
- `render --open`は生成したトップページを開く。`--check`とhookではブラウザを開かない。
- Python実装は例外、ファイル処理、YAML、Doc/config、Git、各コマンドとparserへ分離した。旧CLIの入口・公開名・直接差替えの互換経路を保ち、引数・終了状態・生成物を既存テストで確認する。

## 導入と移行

Nodeは22以上、Pythonは3.11以上。Nodeの初回配布はGitHubの検証済みtgzを使い、本体をnpm/PyPIへ公開しない。公開前は実在する完全Git SHAへ固定したソース導入を使い、未公開のRelease URLを作らない。ローカル導入を基本とし、global導入は利用者が選んだ場合の別範囲とする。詳細は[導入・更新手順](/agents/install-okf.md)。

HTMLのCLI既定出力は`_site/`。旧来のMarkdown隣接配置を続ける場合は`--output docs`などで明示する。旧出力を整理する場合は`--cleanup-from`の計画表示と所有物検証・退避を確認する。既存ファイルの全置換となる`init --force`を移行手段として使わない。詳細は[出力整理](/render/output-cleanup.md)。

Copilot/Codex/Claude向けのリポジトリ終了hookは共通advisory adapterへ接続し、失敗はstderrへ表示する。advisoryのexit0だけから生成成功を判断しない。手動のstrict renderは失敗状態を保持する。プロジェクトの信頼設定やツール側のhook対応が必要で、利用者のglobal設定を自動変更しない。実エージェント終了イベントの接続試験は未実行であり、ローカルadapter検証とは区別する。ツール・CLI/IDE/cloudごとの差は[終了hookガイド](/agents/completion-hooks.md)を参照する。

## 配布検証と試行版の限界

既存の検証はPython/Nodeの機能・比較、文書lint/index/render、配布guards、実tgzの必須28パスを対象とする。共通資産16パスはdefaults1、閲覧assets3、scaffold12である。ローカルと隔離した一時prefixのglobal導入を確認し、実利用者のglobal環境は変更しない。Pythonのソース導入は継続するが、このReleaseのassetはNode tgz・manifest・SHA256SUMSであり、Python wheel/sdistの配布ではない。

初回タグ用ActionsとDraft生成はまだ実行していない。将来の対象タグ/完全SHAで全jobを確認し、Ubuntuで一度作った同じarchiveをWindows/Ubuntu・Node22/24で検証する。Windowsや利用者環境で再packしたものを検証済みassetとして代用しない。公開前にassetのhashとmanifest、元artifactのバイト一致を確認する。[公開手順](/agents/release-node.md)を検証・承認の正本とする。

PreReleaseは試行版である。実在する過去Releaseからの更新互換性は初回公開前には検証できず、合成した旧版fixtureによる復旧テストをその証拠にしない。共有文書の自動逆引きは設定したcode_globsの範囲であり、本文内容の正しさや全AI製品での動作を保証しない。既存文書・設定・hookを保持し、対象版へ固定して試す。
